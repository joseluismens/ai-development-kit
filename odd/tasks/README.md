# ODD task documents

Create one feature document here only for substantial, authorized work. Do so after exploration and before editing source code. Do not create one for small, understood changes.

Use a descriptive, kebab-case name, for example `customer-export.md`. Keep the document as the working record of scope, acceptance criteria, tasks, evidence, and next step. Do not mark a task complete without observed evidence.

Template: `odd/tasks/FEATURE-TEMPLATE.md`.
